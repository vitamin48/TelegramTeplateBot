# Telegram Bot Template Pro 3.0 (aiogram 3, Postgres, Redis, ARQ)

Это продвинутый шаблон для создания Telegram-ботов на aiogram 3, основанный на лучших практиках production-ready приложений.

## Ключевые особенности

- **PostgreSQL**: Надежная и масштабируемая база данных вместо SQLite.
- **Redis**: Хранение состояний FSM, что предотвращает потерю данных при перезапуске.
- **Arq (фоновые задачи)**: Выполнение "тяжелых" операций в отдельном процессе (воркере), не блокируя основного бота.
- **.env**: Безопасное хранение конфигурации и секретов.
- **Готовые Middlewares**: Защита от флуда (троттлинг) и управление сессиями БД.
- **Гибкое управление админами**: Права хранятся в базе данных и могут меняться "на лету".
- **Продвинутое логирование**: Цветные логи в консоли, запись в файл и отправка критических ошибок в Telegram.

## Настройка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/vitamin48/TelegramTeplateBot
    cd TelegramTemplateBot
    ```
2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
    ```
3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Настройте окружение:**
    - Убедитесь, что у вас установлены и запущены **PostgreSQL** и **Redis**.
    - Создайте базу данных в PostgreSQL.
    - Скопируйте `.env.example` в `.env` и заполните его вашими данными (токен бота, данные для подключения к БД и Redis, ID лог-чата).
5.  **Запустите воркер фоновых задач:**
    В одном терминале запустите воркер, который будет слушать очередь задач:
    ```bash
    arq worker.WorkerSettings
    ```
6.  **Запустите бота:**
    В другом терминале запустите основного бота:
    ```bash
    python bot.py
    ```
